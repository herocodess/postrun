## How the pieces connect

- `pnpm serve` (root) runs `next build` (static export to `ui/out`) and then starts the core server, which serves `ui/out` at `/` and the adapter output at `/api/session`. One URL: http://127.0.0.1:1234/.
- `pnpm dev:core` starts only the core server. `pnpm dev:ui` starts Next dev on 127.0.0.1:3000 with `/api/*` proxied to the core server. Use both for UI iteration with hot reload.
- The Next config is mode-dependent on purpose: rewrites exist only in dev, `output: "export"` only in build. Static export does not support rewrites.
- Server port precedence: `--port` flag, then `PORT` env, then 1234. Host is hard-coded to 127.0.0.1 and not configurable.

## Known rough edges

- Killing the `pnpm serve` parent process from a script does not kill the node child (pnpm -> pnpm -> tsx -> node). Ctrl-C in a terminal is fine because the whole foreground group gets SIGINT.
- The server loads the captures once at start. Restart to pick up new capture data.
- Vite was removed; the earlier Vite UI is gone. `core/src/ui` no longer exists.
- `next build` rewrote `ui/tsconfig.json` on first run (jsx react-jsx, extra include). That is Next's normal behavior and the file is the current state.
- `pnpm install` warned about ignored build scripts for esbuild. Harmless; run `pnpm approve-builds` if you want them.
