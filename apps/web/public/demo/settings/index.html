Notifications and updates

Tell me when a session keeps failing
A desktop notification when a running session fails three steps in a row. Once per streak.
Check for new versions
Once a day, asks npm for the latest Postrun version. It is the only time Postrun contacts the internet, and only when this is on.

Appearance

Theme
Remembered in this browser.
Sidebar
Collapsed shows icons only, with names on hover. You can also use the button at the bottom of the sidebar, or press [ anywhere.

Storage

Stored in ~/.postrun, readable only by you
Keep raw logs for
Sessions stay complete either way. Raw logs are only needed to rebuild a session.
Back up your sessions
One file with every session, to keep or to move to another computer. It is not redacted: keep it private.
Delete everything Postrun recorded
Removes every session and their raw logs from this computer, overwritten on disk. New sessions are still recorded. This cannot be undone.

Account

Not signed in
Recording and review never need an account. Accounts arrive with sharing: a link to one session, for someone you choose.
