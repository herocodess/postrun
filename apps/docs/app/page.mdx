# Introduction

Postrun is the flight recorder for coding agents. It records every command, edit and file your agents touch, on your own machine, so you can review the whole session afterwards and share a redacted report when someone else needs to see it.

Install it with `npm install -g postrun` and run `postrun setup`. The [quickstart](/quickstart/) walks through it.

## Where you'll use Postrun

| Where | What it's for | Account? |
| --- | --- | --- |
| The `postrun` command | Installs, starts and checks the recorder; `postrun share` and `postrun feedback` | No |
| The review app, `http://127.0.0.1:1234` | Reading and reviewing sessions, exporting, the **Share** button, **Feedback** | No |
| [app.postrun.app](https://app.postrun.app) | Your share links (open counts, turn off), connected computers, feedback | Free, only for sharing |
| [postrun.app](https://postrun.app) and these docs | What Postrun is, the changelog, how to use it | No |

A typical first day:

1. `npm install -g postrun && postrun setup`. The review app opens.
2. Work with Claude Code or Cline as usual. Sessions appear in the review app as they happen.
3. Open a session to review it: the timeline, what changed, risk flags, your verdict.
4. Need someone else to see it? Click **Share** on the session. The first time, connect a free account; after that, copy the link.
5. See who opened your links, or turn them off, at app.postrun.app. The review app's sidebar has a **Share links** shortcut.

## What Postrun records

A **session** is one run of one agent against one working directory. Inside it, each **turn** starts with your prompt, and each turn is a sequence of **steps**: the smallest unit Postrun records. A step is one of:

| Step type | What it holds |
| --- | --- |
| `message` | Your prompt or the agent's reply. |
| `command` | A shell command, with its output, exit code and working directory. |
| `edit` | A file write or edit, with the before and after text. |
| `read` | A file the agent read, with the line range. |
| `other` | Any other tool call, kept as the raw payload. |

Every agent's own log format is normalized into these same steps, so a Claude Code session and a Cline session read the same way. The full shape is in the [event schema](/reference/schema/).

## How the pieces fit

```text
agent ──► capture ──► store ──► review app
           │           ~/.postrun/postrun.db     http://127.0.0.1:1234
           │
           └─ adapters normalize each agent's logs into v1.2 steps

store ──► export ──► one redacted HTML report you can send
                 └──► share link on app.postrun.app, only when you ask
```

- **Capture** watches your agents while they work: a local telemetry receiver and hooks for Claude Code, the task store for Cline.
- **The store** is a SQLite file in `~/.postrun`, readable only by your user account.
- **The review app** runs on `127.0.0.1:1234` and updates live as sessions are written.
- **Export** writes one session to a single HTML file, with secrets masked, for you to share on purpose.
- **Share links** upload that same redacted file to [app.postrun.app](https://app.postrun.app) and give you an unlisted link that expires. This is the only part that needs an account, and nothing is uploaded unless you ask for a link.

<Callout type="tip" title="Local by default">
  Nothing leaves your machine unless you export a session. The recorder and the review app listen on `127.0.0.1` only, and Postrun has no telemetry. See the [security model](/security/).
</Callout>
