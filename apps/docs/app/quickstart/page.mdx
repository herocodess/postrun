# Quickstart

Two commands take you from nothing to recording. Postrun then runs quietly in the background, and every Claude Code and Cline session you work in shows up in the review app at `http://127.0.0.1:1234/`.

## Requirements

- macOS or Linux. Windows is not supported yet.
- Node.js 22.13 or newer. Check with `node --version`.
- Claude Code or Cline, if you want to record one of them. Any other agent can push sessions through the [ingest API](/capture/other-agents/).

## 1. Install

```bash
npm install -g postrun
```

The package has no dependencies and nothing to compile.

## 2. Set up

```bash
postrun setup
```

This:

1. Adds Postrun's hooks and telemetry settings to `~/.claude/settings.json`. Your original file is saved once to `~/.claude/settings.json.postrun-backup`, and everything else in it is kept as it is. See [Claude Code](/capture/claude-code/).
2. Finds Cline, if you have it. Nothing in Cline needs to change.
3. Starts Postrun in the background.
4. Asks whether Postrun should start when you log in. The answer defaults to yes.
5. Opens the review app in your browser.

It finishes with:

```text
Postrun is recording. Review your sessions at http://127.0.0.1:1234/
```

<Callout type="warn" title="Restart Claude Code once">
  Claude Code reads `settings.json` only when it starts. A Claude Code session that was already open during setup is not recorded until you quit it and start `claude` again.
</Callout>

If you already send Claude Code telemetry somewhere else, setup leaves that alone and records from hooks only: every prompt, command, edit and reply is still recorded, but cost and token counts are not.

## 3. Work as usual

Use Claude Code or Cline as you normally would. Postrun writes a Claude Code session at the end of each turn, and a Cline session shortly after Cline saves it. You can review a session while the agent is still working.

## 4. Review

```bash
postrun open
```

The session list shows every recorded session, newest first. Click one to see the files it touched, the commands it ran and the full timeline. See [Reviewing sessions](/review/).

## 5. Share one session

When someone else needs to see what happened, export a single session as one redacted HTML file. Click **Export report** on the session page, or from the terminal:

```bash
postrun sessions              # find the session id
postrun export <session-id>   # writes postrun-<agent>-<date>-<id>.html here
```

The command prints every value it masked. Check them before you send the file. See [Exporting and redaction](/export/).

## Is it working?

```bash
postrun status    # running or not, and where the review app is
postrun doctor    # every check, with a fix for each problem
```

## Updating

```bash
npm install -g postrun@latest
postrun setup
```

Setup restarts the background process on the new version. Your sessions are kept.

## Removing Postrun

```bash
postrun uninstall
npm uninstall -g postrun
```

`postrun uninstall` takes Postrun's hooks and settings out of Claude Code, stops it, turns off start at login, and asks whether to delete your recorded sessions. Your own Claude Code settings are left exactly as they were.

## Where things live

| Path | What it is |
| --- | --- |
| `~/.postrun/postrun.db` | The session store. |
| `~/.postrun/captures/` | Raw Claude Code hook and telemetry logs, one folder per session, removed 24 hours after a session goes quiet. |
| `~/.postrun/bin/capture-hook.sh` | The hook script Claude Code runs. |
| `~/.postrun/postrun.log` | What the background process did, for troubleshooting. |
| `~/.claude/settings.json.postrun-backup` | Your original Claude Code settings, saved before the first change. |
| `~/.postrun/account.json` | Only after `postrun login`: this computer's sign-in for share links. |

Everything under `~/.postrun` is readable only by your user account. Nothing is sent anywhere unless you make a [share link](/share/).

## Share a session

When someone else needs to see what an agent did, open the session in the review app and click **Share**. The first time, **Connect account** opens app.postrun.app in a new tab: sign in with GitHub or an email link and approve this computer. After that, **Create link** gives you a link that expires. Prefer the terminal? Run `postrun login` once, then `postrun share <session-id>`. See [Share links](/share/).
